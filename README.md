# jhentao-public-media

震縚跆拳道淡水館｜**已核准、可公開發布**的最終圖片素材庫。

> 本庫為 **Public**。任何放進來的檔案，全世界都看得到。

## 用途
提供 Metricool 等排程工具讀取公開圖片直連網址，供 Facebook／Instagram 貼文自動發布。

## 只允許存放
- 經營者已核准公開發布的**最終成品圖片**（PNG／JPG）
- `MANIFEST.md`（索引，只含檔名、用途、SHA-256、核准日期、發布日期）

## 嚴禁存放
- 學費、月繳、期繳、服裝費、優惠等**任何價格資訊**，及畫面中含價格的圖片（含原 DM）
- 未核准的草稿、設計中的版本、原始設計檔（PSD／AI／Canva 原檔）
- 學員姓名、學校、聯絡資料；未取得法定代理人公開授權的未成年人照片或影片
- 內部文件、Token、金鑰、帳號密碼、對話紀錄
- 原始 Logo／印泥章／卡通人物母檔（品牌視覺母檔另行保管）

## 命名規則
`jhentao_<貼文序號>_<類型>_<版本>_<SHA-256 前 8 碼>.png`
例：`jhentao_01_card_v3_c0542e38.png`
- **已上線的檔案不得覆蓋或改內容**；修改一律新增新版本檔名。
- 舊版保留，避免已排程貼文的網址失效。

## 資料夾
- `cards/`：Facebook／Instagram 圖卡
- 之後如需要再增設 `reels-covers/`、`events/`，須先更新本文件。

## 新增檔案流程（每次）
1. 經營者在聊天中明確核准該圖（記錄核准日期）。
2. 檢查圖片：無價格、無個資、Logo 未變形、無白色矩形。
3. 以命名規則存入，計算 SHA-256，更新 `MANIFEST.md`。
4. 用無登入狀態驗證直連網址能讀取完整圖片。
5. 才能附到 Metricool 並啟用排程。

## 管理規則
- 只有經營者或其明確授權者可新增、刪除檔案。
- AI 助理只可新增「已核准」的檔案，不得自行刪除、改名或覆蓋。
- 已發布且仍在排程中的圖片，不得刪除。
- 發現誤放敏感內容：立即移除，並評估是否需要清除 Git 歷史（改密碼與金鑰一併處理）。
- 不放 GitHub Pages、Actions、Webhook 等額外功能，除非經營者另行核准。
- 每月檢查一次：檔案是否都在 MANIFEST、是否有不該存在的檔案。
